# Supported platforms

The public package engine is Node `^22.23.2 || >=24.16.0 <25 || ^26.7.0`. The v0.2.2 candidate is accepted on native Apple Silicon macOS and native Windows x64, with exact-artifact checks on Node 22.23.2, 24.19.0, and 26.7.0. Other native architectures are not claimed without physical acceptance evidence.
