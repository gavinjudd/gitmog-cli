# Supported platforms

The package engine is Node `^22.23.2 || >=24.16.0 <25 || ^26.7.0`. Canonical development and
builds use Node 24.19.0. Public CI exercises standard hosted x64 and ARM64 lanes; a platform is
claimed for a release only after the exact packed artifact passes there. The v0.2.2 historical
claim remains native Apple Silicon macOS and Windows x64.
