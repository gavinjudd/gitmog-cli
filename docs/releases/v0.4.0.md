# Git Mog v0.4.0 — Optional Private Context and Evidence Clarity

Git Mog remains public-only by default. `--private-context` can add source-free aggregate context
from selected private repositories for the authenticated participant; `--public-only` suppresses
every private prompt and endpoint. A separate GitHub App provides read-only metadata and contents
access, and installations that grant all repositories are refused. The authenticated GitHub
identity must match exactly one requested handle.

Private Context is additive. It cannot change the canonical public score, winner, margin, rounds,
verdict, score coverage, evidence, battle key, source analysis, Code DNA, or Code Quality Preview.
Every mixed-context output identifies the participant who added private context and states that the
winner uses public evidence only. A one-sided result is not represented as a private battle or as a
comparable head-to-head score.

The private token and source remain in memory for one invocation. Git Mog does not cache a private
result, repository identifier, path, URL, commit identifier, or source excerpt. Repository names
and paths are not shared. The app has no private key, client secret, webhook, write permission, or
organization permission. Target repositories are accessed through bounded REST requests; they are
never cloned, installed, imported, built, tested, evaluated, or executed.

Public evidence presentation now distinguishes request-budget limitations from supported-source,
eligible-source, and attribution limitations. Sign-in is offered only when more public requests can
materially help. Test metrics use literal names and denominators, visible round support stays in
its scoring category, duplicate factual receipts reuse one marker, and matching insufficient
quality results collapse to one concise explanation.

TypeScript and JavaScript remain the supported Code Quality Preview languages. Quality Judge
remains informational with `scoreInfluence: 0`. Private Context measures only the deliberately
selected repositories and does not provide independently verifiable private evidence. Git Mog
v0.3.1 remains available.
