# Git Mog v0.3.0 — Quality Judge Preview

Git Mog v0.3.0 adds a visible, parser-backed `CODE QUALITY · PREVIEW` panel. It reports maintained
codebase evidence separately from publicly attributed code. Insufficient attribution is not
negative evidence.

TypeScript and JavaScript are preview-supported through the pinned TypeScript 6.0.3 AST parser.
Python, Go, and other languages are unsupported and reduce preview coverage rather than quality.
The versioned sampling ceiling is three substantial repositories, 18 files, 20 KiB per file, and
300 KiB of decoded source per profile. Quality collection is bounded to 21 source and 12
attribution request opportunities per profile at the complete authenticated tier.

Target repositories are never cloned, installed, imported, built, tested, evaluated, or executed.
Raw source is process-only and is never stored, logged, uploaded, or included in receipts. The
packed package remains zero-runtime-dependency with no install
lifecycle, native addon, or runtime download; it adds one checksummed parser asset under
`dist/parsers/`.

Quality Preview has no effect on the canonical score, score coverage, rounds, winner, margin,
verdict, battle key, or existing evidence. Its compatibility fields are
`activation: "preview-only"` and `scoreInfluence: 0`; its policy is informational-only.

Contributors can clone the public upstream, bootstrap the pinned toolchain, run the complete merge
gate, add synthetic fixtures, and build the exact package without private files. See
`CONTRIBUTING.md`, `docs/QUALITY_JUDGE.md`, and `docs/QUALITY_VALIDATION.md`.
