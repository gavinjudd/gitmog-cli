# Support

Use GitHub Discussions Q&A for usage and contributor questions. Use issue forms for reproducible
bugs, feature proposals, documentation problems, language support, and Quality Judge metric
reports. Security vulnerabilities belong in GitHub private vulnerability reporting as described
in `SECURITY.md`.

Do not post credentials, private source, raw target source, or personal information. Maintainers
cannot promise response times or individual consulting. Git Mog is entertainment software and
does not provide employment, legal, security-audit, or professional-assessment advice.
