# Synthetic calibration fixtures

These files were authored for Git Mog and are released under the repository's MIT license. They
contain no copied public or private source and are not human judgments. They exercise the
calibration tool boundary and the activated TypeScript/JavaScript parser lanes only.

Python and Go fixtures are intentionally absent because those quality lanes are unsupported in
v0.3.0. Adding a file does not activate a language; follow `docs/ADDING_A_LANGUAGE.md`.
